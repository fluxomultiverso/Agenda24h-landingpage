Política de Privacidade — LGPD

Última atualização: 29 de maio de 2026

1. Introdução

Esta Política de Privacidade descreve como os dados pessoais são coletados, utilizados e protegidos pela plataforma "Fluxos Inteligentes para Whatsapp".

2. Dados Coletados

Poderemos coletar:

  • nome;
  • telefone;
  • e-mail;
  • mensagens;
  • informações de agendamento;
  • IP;
  • dados de acesso;
  • informações de pagamento;
  • dados enviados pelo cliente.

3. Finalidade do Tratamento

Os dados poderão ser utilizados para:

  • automações;
  • atendimento;
  • envio de notificações;
  • agendamentos;
  • lembretes;
  • suporte;
  • melhorias da plataforma;
  • análises internas;
  • segurança operacional.

4. Compartilhamento de Dados

Os dados poderão ser compartilhados com:

  • plataformas de pagamento;
  • APIs de inteligência artificial;
  • serviços de hospedagem;
  • provedores de infraestrutura;
  • serviços integrados pelo cliente.

5. Bases Legais

O tratamento poderá ocorrer com base em:

  • consentimento;
  • execução de contrato;
  • legítimo interesse;
  • cumprimento de obrigação legal.

6. Direitos do Titular

O titular poderá solicitar:

  • acesso aos dados;
  • correção;
  • exclusão;
  • portabilidade;
  • revogação de consentimento.

Solicitações poderão ser feitas pelo e-mail: contato@multiverso360.com.br

7. Retenção dos Dados

Os dados poderão ser mantidos enquanto houver relação contratual ou obrigação legal aplicável.

8. Segurança

São adotadas medidas técnicas e organizacionais para proteção dos dados, incluindo:

  • controle de acesso;
  • autenticação;
  • criptografia quando aplicável;
  • monitoramento de segurança.

9. Cookies

A plataforma poderá utilizar cookies para melhorar a experiência do usuário e fins analíticos.

10. Alterações

Esta política poderá ser alterada periodicamente.

O uso contínuo da plataforma representa concordância com eventuais atualizações.
